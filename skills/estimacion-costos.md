# Skill — Estimación de Costos

## Variables que afectan el precio

| Factor | Impacto |
|---|---|
| Número de nodos | +15% por cada 10 nodos extra sobre la base |
| Integraciones con APIs externas | +$150.000 COP / +$35 USD por cada API nueva |
| Lógica condicional compleja | +20% al total |
| Agentes de IA incluidos | +$300.000 COP / +$75 USD por agente |
| Manejo de errores robusto | +10% al total |
| Documentación entregable | +$200.000 COP / +$50 USD |
| Urgencia (entrega < 3 días) | +30% al total |

## Reglas de cotización

1. **Nunca dar precio exacto sin entender el alcance completo**
2. **Siempre dar rango** (mínimo – máximo) no precio fijo
3. **Cobrar por separado** análisis, construcción y mantenimiento
4. **Incluir una ronda de ajustes** en el precio base — la segunda ronda se cobra
5. **Anticipos:** 50% al inicio, 50% al entregar
6. **Proyectos > $5.000.000 COP / $1.200 USD:** considerar pago en 3 cuotas (40/40/20)
